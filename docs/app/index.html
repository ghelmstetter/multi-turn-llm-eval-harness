Run an eval from the command line

Everything the web app shows comes from the same engine as these commands. The command line runs any suite, saves the results and writes a self-contained report you can open in any browser.

1. Install

You need Node.js 20 or later and Git. There's nothing else to install: the harness has no dependencies. In a terminal:

git clone https://github.com/ghelmstetter/multi-turn-llm-eval-harness
cd multi-turn-llm-eval-harness
npm test

Run every command in these instructions from that folder. To get later updates, run git pull there.

2. Try it free, with mock models

npm run demo

Then open results/demo/report.html in your browser. Mock models need no keys and cost nothing; their numbers only demonstrate the report.

3. Add an API key

Create a file named .env in the harness folder with the key for each vendor you'll use, one per line:

GEMINI_API_KEY=your-key-here
OPENAI_API_KEY=your-key-here
ANTHROPIC_API_KEY=your-key-here

The file is ignored by Git, so it won't be committed. Never paste keys into chats, issues or screenshots.

First time? Start with : install, a free demo and your API key.

1. Check the cost and time, for free

node src/cli.js estimate --suite suites/tutor-es --targets examples/targets.json

This shows the estimated cost and time without calling any model. A full run of the tutor suite costs about $1 and takes about half an hour with Gemini Flash.

2. Run it

node src/cli.js run --suite suites/tutor-es --targets examples/targets.json --out results/my-run

It shows the estimate and asks before starting, then prints progress with the time left. When it finishes, open results/my-run/report.html. Spending caps keep it safe: $1 per run and $5 per day by default; a run that reaches a cap stops cleanly and keeps what it finished.

Useful options

OptionWhat it doesDefault
--cases a,bRun only some casesall
--turns NAssistant turns per conversation6

--compare a,bWhich two targets from the targets filethe first two
--max-usd XSpending cap for this run1.00
--mockMock models: no keys, no costoff
--yesDon't ask before runningoff

For every command and option: node src/cli.js. The README covers how the modes and graders work.

Settle a close case

If a case is "not settled", the report's By case section lists how many more repeats would likely settle it, with the cost, time and the exact command to copy, like:

node src/cli.js extend results/my-run/results.json --cases english-only --repeats 3

Each case can be extended once, so use the suggested number rather than adding a few at a time.

Compare two runs

node src/cli.js compare results/run-a/results.json results/run-b/results.json --out compare.html

Shows what changed between two runs of the same suite, overall and case by case, and whether each change is more than noise.

Test your own product

Copy an example suite, edit it, and check it as you go:

node src/cli.js validate --suite suites/my-product --targets my-targets.json

The guide to writing a suite walks through it, and takes about an hour for a first useful suite.
